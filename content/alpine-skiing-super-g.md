## Basic Information

Super-G (Super Giant Slalom) is an alpine skiing speed discipline governed by the FIS, sitting between downhill and giant slalom: one timed run on a long course with fewer, wider turns than giant slalom. It is a core Olympic event.

## Rules

Under FIS rules each athlete gets one timed run (plus training runs), and the fastest time wins. The course has a set vertical drop and a smaller number of direction changes than giant slalom, producing higher speeds. Missing a gate means disqualification; equipment must meet FIS specifications, including the mandatory helmet.

## History

Super-G was added to the Olympic program at Calgary 1988 and to the FIS World Championships in 1987. It rewards the ability to carry speed through terrain while still making clean turns. Notable champions include Hermann Maier (AUT), Lindsey Vonn (USA) and Aleksander Aamodt Kilde (NOR).
