## Basic Information

Kakuro ('cross sums') is the numeric crossword invented by Dell in 1950: fill a grid so that each row/column run sums to the clue, using digits 1–9 without repetition. Within the mind, board and card games on this site, its closest relatives are [Sudoku](sudoku.html), [Crossword](crossword.html), [Nonogram](nonogram.html); the related pages are listed under Important Links (Nikoli, n.d.).

## Rules

Grid with clue numbers in split cells; each run of white cells must sum to the clue with distinct digits 1–9; no repeats within a run (Nikoli, n.d.).

## History

Invented by Dell Magazines (1950, New York); popularized in Japan by Nikoli (which popularized it as kakuro); the Kakuro2 and Crosssum diagrams (PD/CC0) show example grids (Wikipedia, n.d.-a).
