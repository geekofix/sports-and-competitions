Set

≈ 2 min read

Basic Information Rules History Sources Important Links

Basic Information

Set is the real-time card game invented by Marsha Falco in 1988 (popularized 1991, Mensa Select): 81 cards with 4 attributes (number, shape, shading, color); players race to find 'sets' of 3 cards where each attribute is all-same or all-different. Within the mind, board and card games on this site, its closest relatives are Dobble, Halli Galli, Uno; the related pages are listed under Important Links (Set Enterprises, n.d.).

Figure: Miles at English Wikipedia. (2005-04-24). Three Set cards showing all variations [Photograph]. Wikimedia Commons. Public domain. https://commons.wikimedia.org/wiki/File:Set-game-cards.png

Rules

81-card deck; 12 cards laid out, +3 if no set; a set = 3 cards with each attribute identical or all different across the three; most sets; most sets wins. World championship— Set world championships are held (Set Enterprises, n.d.).

History

Designed by Marsha Falco (geneticist) in 1988, published by Set Enterprises 1991; the PD 'Set-game-cards' image (2005) shows an example set; the custom 'Projective Set' deck (2015) shows its math depth (Wikipedia, n.d.-a).
