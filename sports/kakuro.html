Kakuro

≈ 1 min read

Basic Information Rules History Sources Important Links

Basic Information

Kakuro ('cross sums') is the numeric crossword invented by Dell in 1950: fill a grid so that each row/column run sums to the clue, using digits 1–9 without repetition. Within the mind, board and card games on this site, its closest relatives are Sudoku, Crossword, Nonogram; the related pages are listed under Important Links (Nikoli, n.d.).

Figure: Maths54. (2010-07-27). A kakuro puzzle grid [Diagram]. Wikimedia Commons. Public domain. https://commons.wikimedia.org/wiki/File:Kakuro2.jpg

Rules

Grid with clue numbers in split cells; each run of white cells must sum to the clue with distinct digits 1–9; no repeats within a run (Nikoli, n.d.).

History

Invented by Dell Magazines (1950, New York); popularized in Japan by Nikoli (which popularized it as kakuro); the Kakuro2 and Crosssum diagrams (PD/CC0) show example grids (Wikipedia, n.d.-a).
