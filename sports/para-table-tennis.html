Para Table Tennis

Basic Information Rules History Sources Important Links

Basic Information

Para table tennis is the Paralympic version of table tennis, played under the rules of the International Table Tennis Federation (ITTF) with slight modifications for athletes with impairments (ITTF, n.d.). Athletes are classified into eleven classes: classes 1 to 5 compete in wheelchairs, classes 6 to 10 compete standing, and class 11 is for players with an intellectual disability; within each group, a higher number means more function (Wikipedia, n.d.-a). The sport has been on the Paralympic program since the first Games in Rome 1960, governance moved from the IPC to the ITTF in 2007, and with more than 40 million players in over 100 countries it is the third most played Paralympic sport (International Paralympic Committee, n.d.). Women compete in the same eleven classes as men, and among today's stars are Poland's Karolina Pęk, gold medallist in women's class 9 singles at the Paris 2024 Paralympics, and Egypt's Ibrahim Hamadtou, a two-time Paralympic champion in class 4 — both pictured below (International Paralympic Committee, n.d.).

Rules

Para table tennis follows the standard ITTF rules with a few adaptations, mainly around the serve when the receiver uses a wheelchair and the wider table legs that allow a wheelchair to pass (ITTF, n.d.). Matches are best of five sets, each set played to 11 points and won by two clear points (ITTF, n.d.). Wheelchair classes 1 to 5 play on the standard table, and standing classes 6 to 10 follow the ordinary laws of table tennis without exceptions (ITTF, n.d.). Classification is carried out by ITTF-trained classifiers who examine each athlete's functional ability before competition (Wikipedia, n.d.-a). Events at the Paralympics are men's and women's singles and team within each class, and the rules are identical for both genders; team events pair classes (for example class 1-2, 3, 4-5) with the same scoring for all (International Paralympic Committee, n.d.).

History

Table tennis for athletes with disabilities dates back to the 1950s in Britain, where Stoke Mandeville Hospital used the game in rehabilitation; it entered the first Paralympic Games in Rome in 1960 (International Paralympic Committee, n.d.). The International Paralympic Committee governed the sport until 2007, when the ITTF took over para table tennis as the first international federation to govern both able-bodied and para disciplines (Wikipedia, n.d.-b). The roots of the sport go back to Sir Ludwig Guttmann's Stoke Mandeville Games of 1948, which grew into the first Paralympic Games in Rome 1960 — table tennis has been on the Paralympic program ever since, making it one of the founding sports of the Paralympic movement (International Paralympic Committee, n.d.). The World Para Table Tennis Championships run on the ITTF calendar alongside the able-bodied world championships (ITTF, n.d.).
